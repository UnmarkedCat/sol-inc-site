# Sol, Inc. site

Public pages for the Sol, Inc. app, served by GitHub Pages at https://unmarkedcat.github.io/sol-inc-site/

- `index.html`: Support (the App Store's Support URL)
- `privacy/index.html`: Privacy Policy in English and Spanish (the App Store and Google Play privacy policy URL)

Plain HTML and CSS, no build step. The game itself lives in the private `sol-inc` repo. Fredoka is self-hosted under the SIL Open Font License (`assets/Fredoka-OFL.txt`).
